** githooks — dojo↔specs
:PROPERTIES:
:ID: scripts-githooks
:END:

Tracked under =scripts/githooks/=; enable with
=bash scripts/verify/specs_sync.sh --install= (=core.hooksPath=).
=post-checkout= / =post-merge= mirror the branch, then fast-forward to the
pin SHA only when =specs.lock='s =branch== matches dojo (avoids a stale pin
undoing the mirror); =pre-commit= restamps the pin. Hand =--checkout= still
follows the lock's branch. Refuses conflict-marker locks. Hand-run the verify
script when a hook refuses (dirty or diverged specs tree).
