** The consistency seam — a preorder is not an identity

Under the magnitude projection, =[3,0] <= [0,3]= and =[0,3] <= [3,0]= are both 1,
while the provisional whole-value =[3,0] == [0,3]= is 0. That is coherent as a total
PREORDER whose equivalence classes are equal-length arrows; it is not a partial order
and it is not identity. If both are shipped, the contract must say so in one voice:
the six comparison glyphs are one semantic package, not six independent registrations.
A child who writes =(a <= b) and (b <= a)= has not proved =a == b=.

* Infinity — a species still unruled
:PROPERTIES:
:ID: probe-tower-comparison-infinity
:TYPE: question
:END:

The current runtime inherits IEEE: a comparison with +/-Infinity answers a finite
1/0. The rig records four candidate dispositions; it chooses none.

| Expression | Current (IEEE) | preserve operand | NaN | refuse |
|------------+----------------+------------------+-----+--------|
| =1/0 == 1/0= | 1 | Infinity | NaN | domain-refusal |
| =1/0 == -1/0= | 0 | Infinity (left) | NaN | domain-refusal |
| =1/0 > 1= | 1 | Infinity | NaN | domain-refusal |
| =-1/0 < 1= | 1 | -Infinity | NaN | domain-refusal |
| =(1/0)&1= | 0 | Infinity | NaN | domain-refusal |
| =(1/0)^0= | 1 | Infinity | NaN | domain-refusal |

Details a ruling must name:
- Vector ordering and equality already refuse non-finite components while scalar
  comparisons still answer; a uniform species rule must choose between those.
- Preserving the offending operand is order-sensitive: =1/0 == -1/0= reports
  +Infinity and =-1/0 == 1/0= reports -Infinity. Both refuse a condition, but the
  label names different operands.
- Mapping both non-finite species to NaN loses the "left the number line" notice
  that =conditionOf= already distinguishes.
- Refusing at the tower changes statement/frame recovery and needs its own witness.
- Overflow (=(1e308*10)=) is the same species as =1/0=; the rule must name both.

The arithmetic surface splits three ways, and the rule must name all three:
propagates (=abs(1/0)=, =sqrt(1/0)=, =(1/0)//4=), NaN (=(1/0)-(1/0)=,
=0*(1/0)=, =(1/0)/(1/0)=, =mod(1/0,4)=), or a finite limit (=1/(1/0)= is 0,
=exp(-(1/0))= is 0, =atan2(1/0,1)= is 90). The rig records the routes; it
does not choose which finite limits are allowed.

Not decided here. The instrument stays =active= for this layer and the deferred
product rows; the comparison/equality slice is fenced by its tests.
