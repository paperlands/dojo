* Stop/wake isolation trial (P1 remainder)
:PROPERTIES:
:ID: live-rendering-stopwake-plan
:LENS: empiricist adversarial
:END:

P1 left one question open: is there an *authoritative* stop/wake fact a driver can read
at an existing scheduler transition, in O(transitions) rather than the O(frames) reference
reader? [[file:stopwake.mjs][stopwake.mjs]] instruments only existing seams — the exported
=EFFECTS= yield table and the =tick= boundary (produced / building / done) — with no source
edit. The probe mutates the exported table; the runtime is unchanged.

Predictions, fixed before the run:
- Effect transitions expose stop causes for =breath=, =blocked= (dataflow) and =motion=
  (admission install). These are per-kind, per-frame facts, not a scan.
- The deposit path is the =EFFECTS= fallback, not a routed verb; a credit or residency debt
  therefore leaves no effect transition. A debt stop is invisible to a transition reader.
- Wake events (credit return, admission reply, dependency resolution, derived-move drain,
  drain re-seat) are state mutations outside the yield table: no transition fires.
- The =tick= boundary collapses every park kind into one boolean (=building=), so it cannot
  by itself separate breath, debt and pending admission.
- Therefore no O(transitions) stop/wake summary exists yet; authority requires the runtime
  to report the =stepOnce=/=stepFrame= verdict kind and the deposit cause, and to signal a
  suspension-clear wake.

Falsifiers: an effect transition is observed for *every* reference park kind; or a wake is
attributable to a transition; or the =tick= boundary separates park kinds. Any one falsifies
the negative and licenses promotion. Residency is not exercised (no fixture); record that
censoring rather than inventing a bound.

Pilot correction (before the final stop/wake runs): the first instrument collected
transitions only inside =tickCollect=, so the reply, drain and hand-input "zero" counts
measured windows where collection was *off* — they could not establish that no handler
ran. Re-run with collection spanning each controlled wake, one phase tag per window.
A zero inside the window is the falsifier; a zero outside it is nothing.
Recorded distinctions: admission readiness *retains* its suspension; credit availability
precedes the replayed deposit and its clear; a derived move queues with *no* suspension;
a fault clears suspension as the run dies. "Wake" is not "clear". Also: drained is not
committed — read the derived frame's pose, and note the =redrawDerivedPlace= guards that
consume the queue while keeping the last pose.
Certify every zero with a positive control: a forced breath through the same window
machinery must be recorded. The contrast — an effect present when a pump runs, absent
when none does — is what makes a wake zero mean anything. EFFECTS is reachable only
from =stepFrame= via =stepOnce=, i.e. only inside a tick; a wake window without a tick is
structurally empty, which is a fact about the seam, not evidence the wake did nothing.

* Owner census trial (P1 remainder, second step)
:PROPERTIES:
:ID: live-rendering-owner-census-plan
:LENS: empiricist adversarial
:END:

The stop/wake reading says authority must come from each owner, not a universal wake.
[[file:owners.mjs][owners.mjs]] asks, for each natural owner of a stop/eligibility fact,
whether that fact is *routed* by an existing transition or only *read* off cross-cutting
state. It measures; it adds no seam. It also earns the residency case the first instrument
censored.

Predictions, fixed before the run:
- The pacer (breath) and the dependency (dataflow) install are routed; their clears are not.
- The admission verdict lifecycle is not routed: only the install is, as =motion=.
- Channel/credit and stage/residency are deposit-fallback parks: no routed transition.
- The place's queue is not routed; its commit is state (a pose), and the two differ.
- The run's =done=/=error= is state; a routed =ended= comes from the yielding effect, not
  from the run itself.
Falsifier: any owner already routes its eligibility fact at a transition.
Stopping rule: one verdict per listed owner; promote nothing; residency earns its case.
